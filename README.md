# One-Line Laugh Sprint

Entry for the make.fun bounty "One-Line Laugh Sprint"
(u-daring-gecko-25-one-line-laugh-sprint-cda708b2, $5 pool).

`main.py` (pure Python standard library) writes one original funny line,
at most 200 characters, to `/output/entry.txt`.

The line:

> I bought a standing desk to be healthier. Now I sit on a taller chair and look down on everyone — literally and morally.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
